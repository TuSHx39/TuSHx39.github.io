# 节拍器设计

用户目标：在个人静态工具站增加一个可视化节拍器，支持丰富节奏、完整单小节编写、多音色及重音；所有复杂功能可关闭，文案仅包含功能与操作说明。

## 页面与视觉

- 独立入口 `pages/metronome/index.html`，首页启用既有预留入口。
- 原生 HTML/CSS，源码使用 ES modules，并生成独立普通浏览器脚本；无运行时依赖，同时支持本地双击与 GitHub Pages。
- 瑞士风格：浅蓝背景与深蓝文字、平直网格与细线分区，读条、速度、预设、编排和练习控件使用协调的蓝色色块；移除功能下方的解释脚注。
- 使用 Helvetica/Arial 与中文系统字体，数字采用等宽数字。突出 BPM 和与音频同步的分拍水平读条；测速使用独立图标按钮，保留 T 与空格快捷键。
- 默认基础模式：速度 120 BPM、4/4、每拍一次、第一拍重音。只显示拍号、速度、读条、播放、Tap 及音量。
- 高级模式展开节奏预设、音色、单小节编排及可选练习设置；关闭高级模式即播放基础节拍，高级编排保存供下次展开。
- 所有图标按钮有可访问名称、输入有标签、键盘可操作、移动端可使用，尊重减少动态效果偏好。

## 节奏与自由度

- BPM 20–300；只提供每小节 1–12 拍，基准音符固定为四分音符。旧设置中的其他拍单位加载或导入后统一为四分音符，其余配置保留。
- 预设：四分节拍、八分、十六分、前八后十六、前十六后八、附点、Swing、三连音、三连音跳拍、切分、六连音，加上自定义共 12 格。按钮仅显示矢量音符，名称保留为无障碍标签。Swing 百分比 50–75。
- 一小节由各拍独立的均分网格构成，允许每拍 1/2/3/4/5/6/7/8/12/16 格，每格为普通音、重音或休止。每拍单独设置，不限制整小节使用同一网格，支持混合连音与跳拍。偶数网格可逐拍启用成对 Swing。
- 每个事件带精确拍内偏移、力度、音色；预设可以复制到自定义编排继续修改。编辑器每格能直接编辑力度和音色。
- 预设按四分音符拍细分；高密度网格在窄屏中行内滚动，编辑后保留滚动位置。
- 可选首拍重音、预备小节、周期静音练习、渐进提速及自动停止；每项有独立开关。计时和小节数仅播放时累计。
- 首拍重音与第一拍第一格双向绑定：普通或休止关闭开关，重音打开开关；开关操作同步修改该格。开启首拍为休止的预设时，将该格改为重音并转为自定义。播放按实际格类型发声，不额外叠加首拍重音。自定义入口用三个点表示。
- 保存设置与自定义节奏至本地；JSON 导出/导入带版本与校验，不接受超范围或未知结构。

## 音频与同步

- Web Audio AudioContext，用户点击开始后恢复上下文；提前约 100ms 调度，每 25ms 检查。
- 声音合成音色：电子、木块、鼓棒、牛铃、底鼓、踩镲；重音提升力度与音高。
- stop 立即取消已排入的声音并清空可视事件；播放时参数变化立即重排当前小节尚未播放的音，保留拍内进度，取消旧调度而不重播已响过的音。拍号缩短时当前拍按新拍数折回。
- 渐进提速同步显示主 BPM 和滑杆，保存的起始速度不随动画累加；手动修改 BPM 或提速配置后，从当前小节重新计算提速进程。
- 音色衰减按相邻实际音符的时间间隔略微延长，延长量有小幅上限；休止和 Swing 也参与间隔计算。预备小节开关控制下一次启动，正在播放的预备小节仍能即时更改速度与音色。
- requestAnimationFrame 依据 AudioContext 时间显示小节进度和当前格，不用 CSS 动画作为时钟。
- 页面可见性变化时避免补发旧声音；不支持音频时显示具体错误。

## 验证

使用 Node 内置测试验证预设时间、混合网格、重音、休止、Swing、拍号、导入校验和练习配置。浏览器验证启动/停止、节奏编辑、基础模式、保存及窄屏布局；检查控制台和静态资源。
