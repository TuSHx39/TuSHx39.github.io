# 虚拟钢琴

浏览器里的虚拟钢琴：88 键键盘、四种波形合成、踏板延音、和弦 / 转位识别。
纯静态、零依赖、零构建，也**不需要本地服务器**——直接双击 `piano.html` 就能玩。

```
pages/piano/
├── piano.html            结构：读数、设置面板、琴床、踏板条；末尾按顺序引入 6 个脚本
├── piano.css             样式：键床尺寸集中在顶部的 CSS 变量里
├── js/                   传统脚本（非 ES Module），通过全局命名空间 Piano 协作
│   ├── chords.js         → Piano.Chords    和弦识别引擎（纯逻辑，无 DOM / 无音频）
│   ├── synth.js          → Piano.Synth     Web Audio 发声：声部包络与踏板
│   ├── keyboard.js       → Piano.Keyboard  绘制 88 键、指针交互（鼠标 / 触摸 / 连奏）
│   ├── panel.js          → Piano.Panel     设置面板开关与主 / 子页切换
│   ├── store.js          → Piano.Store     设置的 localStorage 持久化
│   └── main.js           粘合层：设置、踏板状态机、显示、初始化（最后加载）
└── tests/
    ├── helpers/load-piano.mjs  按 <script> 顺序在 vm 沙箱里加载脚本
    ├── chords.test.mjs         和弦引擎的乐理用例
    ├── integration.test.mjs    用 DOM / Audio 桩真正跑一遍 main.js
    └── project.test.mjs        HTML ↔ JS ↔ CSS 的一致性自检
```

### 为什么不用 ES Module

浏览器禁止 `file://` 页面加载 `<script type="module">`（跨域被 CORS 拦掉），
一旦用了 `import`，双击 HTML 打开就会得到一个完全没反应的页面。
所以这里用传统脚本 + 全局命名空间 `Piano`：
`file://`、`http://`、GitHub Pages 三种方式都能跑，代价是不能用 `import` 语法。

**新增模块时**：在 `js/` 下写 IIFE，把接口挂到 `Piano.Xxx`，并加进 `piano.html`
末尾的脚本列表（`chords` 最先、`main` 最后）。测试会检查顺序与命名空间。

## 电脑键盘映射

**按「读一行、再读下一行」的顺序**把连续的琴键分配给连续的按键：
数字排先读，然后往下换 QWERTY 排、ASDF 排、ZXCV 排；一行读完换行时音继续升高。
起始音是 C1，于是 **QWERTY 排的 `E` 恰好落在 C3**（往右依次升高）。

| 行 | 按键 | 对应音 |
| --- | --- | --- |
| 数字排 | `1 2 3 4 5 6 7 8 9 0 - =` | C1 → G2 |
| QWERTY | `Q W E R T Y U I O P [ ]` | A2 → E4（`E` = C3） |
| ASDF | `A S D F G H J K L ; '` | F4 → B5 |
| ZXCV | `Z X C V B N M , . /` | C6 → E7 |

**黑键 = `Shift` + 它左边的白键，或 `Alt` + 它右边的白键**，
同一个黑键因此有两种按法、两种写法：

| 黑键 | Shift 写法 | Alt 写法 |
| --- | --- | --- |
| C#3 / Db3 | `Shift+E` → 显示 **C#3** | `Alt+R` → 显示 **Db3** |
| C#4 / Db4 | `Shift+P` → 显示 **C#4** | `Alt+[` → 显示 **Db4** |

琴键上有两种灰色小字：**顶部是电脑按键**（黑键写两行 `⇧E` / `⌥R`，白键一行 `E`），
**底部是这个键的音名**（`C4`、`D4`、`C#4`…每个键都有）。
分别由设置里的「显示键位」和「显示音名」控制。

`⌥` 就是 Alt 键。用 Alt 而不是 Ctrl，是因为 `Ctrl+W`（关标签页）、`Ctrl+T`（新标签页）、
`Ctrl+1…8`（切标签页）这类浏览器快捷键拦不住；**Alt 的原生行为在页面里已被
`preventDefault` 屏蔽**（聚焦菜单栏、`Alt+字母`加速键、`Alt+←/→` 前进后退等），
只有 `Alt+F4` / `Alt+Tab` 这类系统级组合拦不住，而映射里不含这些键。

## 设置

| 项 | 说明 |
| --- | --- |
| 主音量 / A4 基准频率 / 波形 | 合成参数。波形默认 **Piano**（自建谐波频谱 + 击槌噪声 + 低通下滑）；切换波形对之后弹的音生效 |
| 显示音名 | 顶部「当前音」读数 + **每个琴键**底部的音名 |
| 显示键位 | 键内顶部的电脑键盘标注（灰色小字） |
| 识别和弦 | 总开关，关闭后其下两项收起（收起时不留空白） |
| 允许转位 | 打开时给出斜杠读法（`C/E`）；关闭时只认原位，转位一律显示 `-` |
| 踏板设置 → 显示踏板 | 收起底栏，读数与琴床一起平滑下移 |
| 踏板设置 → 踏板反转 | 不踩即延音、踩下反而放音 |
| 踏板设置 → 踏板切换 | 踩一下切换延音开 / 关，松开不改变状态 |

所有设置都会写入 `localStorage`（键名 `tushx39.piano.settings.v2`）。

## 踏板与衰减（按真实钢琴的制音器建模）

| 情形 | 行为 |
| --- | --- |
| 按下琴键 | 起音后进入**自然衰减**：两段指数（先快后慢）+ 低通随时间下滑，高次谐波先消失，衰减完自己停止 |
| 松键、未踩踏板 | 制音器落下 → **快速放音**（τ≈75ms），并且**立刻**从「正在弹奏」里清空 |
| 松手后停顿一下再踩踏板 | **不会被复活**：已被制音的音不允许踏板再接管，避免虚空音（连包络都不再改动） |
| 踩踏板时松键 | 制音器保持抬起 → 音继续**缓速衰减**，期间一直算「正在弹奏」 |
| 抬踏板 | 被踏板保持的音**立刻放掉**；键还按着的音不受影响（制音器由琴键顶着） |
| 音已放完 | 声部被删除，之后**再踩踏板也不会把它变成「正在弹奏」** |
| 踏板保持中的音 | 即使已经衰减到极小，仍算正在弹奏，直到抬踏板才清除 |
| 音高差异 | 和真实钢琴一样，**音越高衰减越快**（C8 约 9 秒、C4 约 20 秒），低音弦拖得久 |

## 和弦识别

`chords.js` 把「正在响的音」当成输入，输出一组按可信度排序的读法：
第一个是主读法，其余作为候选显示在第二行（最多 4 条）。
**单音（含同音重复八度）不是和弦，直接显示 `-`。**

### 升降号（升 / 降拼写）

| 情形 | 规则 |
| --- | --- |
| 单音 | 默认**升号**：`D#4`、`A#4` |
| 成和弦 | 按和弦的**音程关系**定：小三 / 减 / 属七类写降号（`Cm`、`C7` 里的 **Eb**、**Bb**），只有 `C#m / F#m / G#m` 与 `F#` 用升号；大三、sus、加音类只在 `F#` 用升号，其余黑键写 `Db / Eb / Ab / Bb` |
| 斜杠低音 | 与根音用同一套拼写：`Db/F`、`Cm/Eb` |
| 键盘映射按下 | 优先用按键带来的拼写：`Shift+Q` → `C#`，`Alt+W` → `Db` |

### 识别方式（八度内）

把所有音压进一个八度得到音级集合，然后**遍历每个出现过的音作为假定根音**查表。
因此任意排列、任意重复八度都能识别；最低音不是根音时自然得到转位读法：

| 按下的音 | 读法 |
| --- | --- |
| C E G | `C` |
| E G C | `C/E`（斜杠低音） |
| C E G A | `C6`，候选 `Am7/C` |
| C D E G Bb | `C9` |
| C E G Bb D A | `C13` |
| D C E G | `D9sus4`，候选 `Cadd9/D` |

打分 = 词典常用度 + 45（最低音正好是根音时）。词典共 70 个音级集合 / 72 条形态：
三和弦、sus、六和弦、6/9、七和弦（含 m7b5、dim7、mMaj7、7#5、7b5）、add9、
九和弦（含变化音 7b9 / 7#9 / 7#11 / 7b13）、十一 / 十三和弦，以及钢琴上常见的省略五音形态。

同一组音存在多种解释时（例如 `0,3,6` 既是 `dim` 也可读作省略五音的 `m7b5`），
它们在词典中共存，由「常用度 + 最低音是否为根音」共同决定先后。

## 与旧版本的差异

除了拆分成模块，这次同时修掉了旧实现里的几个实质问题：

1. **和弦表重复键**：旧 `ALL_CHORD_MAP` 里 `"0,4,7,14"`、`"0,4,21"` 等键被后面的
   定义静默覆盖，导致带 13 音的属和弦一律报成 `maj13`、add9 报成 `maj9`。
   新词典显式合并重复键并保留最高常用度，并有测试锁死（`0,2,4,7,9,10 → 13`）。
2. **失焦报错**：旧代码在 `blur` 里调用了不存在的 `releaseNote()`，抛错后音符
   不再释放、读数卡住。现在是 `synth.stopAll()` + 复位踏板，有集成用例覆盖。
3. **延音不生效 / 读数残留**：旧代码 `sustainOn ? DECAY_NORMAL : DECAY_NORMAL`
   两边同值，踏板只能改释放行为，且声部靠定时器清理，踏板开着时读数永不消失。
   现在声部由 `OscillatorNode.onended` 回收，显示永远等于实际发声。
4. **黑键错位**：旧黑键是白键的兄弟节点又用了绝对定位，包含块其实是外层固定容器，
   整体高出白键 20px。现在 `#piano` 是定位上下文，黑键尺寸与位置由 JS 实测白键像素得出，
   改 CSS 变量甚至跨响应式断点都不会错位。
5. **移动端**：补上 `viewport`，改用 Pointer Events（多指和弦、拖动连奏），
   设置面板可纵向滚动。
6. **重复代码**：踏板逻辑从四处复制粘贴收敛为 `pedalDown / pedalUp / applyPedalState`。
7. **改成传统脚本**：初版沿用 ES Module，结果双击打开时被 CORS 拦死（页面毫无反应）。
   现在 `js/*.js` 都是普通 `<script>`，并把 DOM 查询挪进 `init()`，
   因此脚本位置和 `file://` 都不再是问题；测试里专门有一条按 `file://` 方式加载的冒烟用例。

### 第二轮调整（按反馈）

8. **单音不再显示和弦**：单音与同音重复八度都读不出和弦，读数直接是 `-`。
9. **踏板改成真实制音器模型**：不踩踏板时松键是快速放音；踩下时是缓速衰减（不是「不衰减」）；
   在放音过程中踩下只放慢衰减速度、不抬高音量；抬踏板立刻放掉被保持的音；
   音一旦放完就删除，再踩踏板也不会复活；踏板保持中的音即使极轻也算正在弹奏。
   旧实现会把这些音的音量**拉回**保持电平，等于踩踏板时音量突变，已修正。
10. **新增 Piano 波形并设为默认**：谐波频谱（PeriodicWave）+ 击槌噪声瞬态 + 随时间下滑的低通，
    配两段指数衰减，模拟真实钢琴的衰减曲线。
11. **次级设置收起后不再留空白**：`.sub-setting` 收起时外边距一起归零（原来每项残留 26px）。
12. **新增升 / 降号区分**：单音默认升号，和弦按音程关系定，斜杠低音跟随根音，
    键盘映射按下的音优先用它自己那套写法。
13. **新增电脑键盘弹奏**：连续按键映射到连续琴键，`Shift+左侧键` / `Ctrl+右侧键` 弹黑键，
    并在键内顶部显示灰色小字标注（设置里可关）。

### 第三轮调整

14. **消灭虚空音**：松手（未踩踏板）后音立刻从「正在弹奏」里清空，并被制音器**锁定**——
    停顿一下再踩踏板既不会让它重新出现，也不会再改动它的包络。
15. **映射改为按行顺序**：数字排先读，再 QWERTY / ASDF / ZXCV，一行读完换行继续升高，
    锚点是 **`E` = C3**（覆盖 C1 → E7）。
16. **每个键都标注音名**：不再只有 C 键，白键黑键底部都写音名（黑键用小一号的灰字）。
    顺带修掉一个真 bug：以前只有「右侧带黑键」的白键才有映射标注，`E`、`B` 这类键被漏掉了。
17. **黑键位置修正**：黑键中心改回落在相邻两个白键的**分界线上**（跨在两者之间）。
    之前的比例把原作者的 `left = 0.7w` 误当成「中心比例」，导致每个黑键都往左偏了约 1/3 个白键宽。
18. **降号改用 Alt**：`Ctrl` 的浏览器快捷键太多（`Ctrl+W`、`Ctrl+T`、`Ctrl+1…8` 拦不住），
    改为 `Alt+右侧键`，并在页面里 `preventDefault` 掉 Alt 的原生行为。

### 第四轮调整

19. **删掉复合和弦**：按反馈移除「复合和弦」识别逻辑（`findPolychords`、相关打分常量、
    `mode` 选项与返回字段）以及设置面板里的「和弦模式」下拉。现在只保留**八度内识别**，
    `允许转位` 开关照旧。低音 + 上层结构不再读成 `C/D` 这类复合写法，
    而是按音级集合解读（例如 D-C-E-G → `D9sus4`，候选里仍有 `Cadd9/D`）。
    测试里加了一条「复合和弦逻辑与设置项已经删干净」的守门用例。
